# counter

Реализуйте функцию `New`, создающую независимую числовую последовательность:

```go
func New(start, step int) func() int
```

Возвращённая функция при каждом вызове сначала увеличивает текущее значение на
`step`, а затем возвращает его. Это тот же контракт, что у примера `counter` из
лекции.

```go
next := New(10, 3)
fmt.Println(next()) // 13
fmt.Println(next()) // 16
fmt.Println(next()) // 19
```

Разные вызовы `New` не должны делить состояние. Глобальные переменные
использовать нельзя.

## Проверка

```shell
go test ./counter/...
```
