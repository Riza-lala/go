# treetransform

Дано бинарное дерево и функция преобразования:

```go
type Node struct {
	Value int
	Left  *Node
	Right *Node
}

type Transform func(int) (int, error)
```

Реализуйте функцию:

```go
func Map(root *Node, transform Transform) (*Node, error)
```

`Map` должна построить **глубокую копию** дерева той же формы, заменив значение
каждого узла результатом `transform`.

Контракт:

- при успешном обходе `transform` вызывается ровно один раз для каждого узла в
  порядке `root → left → right`; при ошибке вызывается только соответствующий
  prefix этого порядка, включая сбойный узел;
- узлы результата должны быть новыми: менять или переиспользовать узлы
  исходного дерева нельзя;
- для `nil`-дерева функция возвращает `(nil, nil)` и не вызывает ненулевой
  `transform`;
- `nil` вместо `transform` возвращает `ErrNilTransform`, даже если дерево
  пустое;
- ошибку `transform` нужно обернуть через `%w`; контекст должен содержать
  исходное значение сбойного узла, а исходную ошибку должно быть возможно
  найти с помощью `errors.Is`;
- после первой ошибки обход прекращается, а частичный результат не
  возвращается: первый результат должен быть `nil`.

Порядок обхода является частью контракта: `Transform` может быть замыканием с
состоянием, поэтому перестановка вызовов меняет наблюдаемое поведение.
